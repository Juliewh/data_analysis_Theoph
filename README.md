# Сравнение регрессионных моделей и статистический анализ

## О проекте:
[Работа](notebook.ipynb) посвящена отработке знаний по математической статистике, построению и сравнению регрессионных моделей, оценке их качества и статистическому анализу линейной регрессии.

В работе исследуется зависимость концентрации теофиллина в крови от времени после приёма препарата на примере данных одного испытуемого. Работа демонстрирует применение регрессионного анализа, методов математической статистики и визуализации для исследования зависимости между переменными и выбора модели с учётом как численных метрик качества, так и содержательной интерпретации.

## Данные:
**Источник:** набор данных ```Theoph — Pharmacokinetics of Theophylline```.

Набор содержит результаты фармакокинетического исследования теофиллина, применяемого при лечении бронхиальной астмы.

В исследовании используются следующие переменные:

* ```Фактор (x)``` — время после приёма препарата, в часах;
* ```Отклик (y)``` — концентрация теофиллина в крови, в мг/л.

Для анализа выбран испытуемый № 1, а также наблюдения, соответствующие условию Time >= 1. После фильтрации получено 8 наблюдений.

## Постановка задачи:
Цель работы — сравнить линейную, квадратичную и показательную регрессионные модели, определить наиболее подходящую для описания исследуемой зависимости и выполнить прогноз концентрации препарата.

## Выполнены необходимые этапы для достижения цели:
* Из исходных данных выбраны необходимые срезы, создана таблицы для работы с данными;
* Проведен первичный анализ данных, построена диаграмма рассеяния и определен характер зависимости между временем и концентрацией теофиллина;
* Построены три регрессионные модели, параметры оценены c помощью метода наименьших квадратов, для показательной модели применена линеаризация с помощью логарифмирования;
* Качества моделей оценены и сравнены с помощью метрик R² (коэффициент детерминации), RMSE (корень из среднеквадратичной ошибки) и MAPE (средняя абсолютная процентная ошибка), подтверждена предварительная гипотеза;
* Выполнен подробный статистический анализ линейной модели: исследованы остатки, рассчитаны стандартные ошибки и доверительные интервалы коэффициентов, проверена статистическую значимость наклона регрессионной прямой;
* Получен прогноз концентрации теофиллина при заданном значении фактора.

## Используемые инструменты:
* ```Python``` - реализация вычислений и регрессионных моделей;
* ```NumPy``` - математические операции и расчёт показателей качества;
* ```Pandas``` - загрузка, фильтрация и обработка данных, формирование таблиц результатов;
* ```Matplotlib``` - визуализация исходных данных, регрессионных кривых и остатков;
* ```SciPy``` — статистические распределения и расчёты для проверки гипотез и построения доверительных интервалов.
